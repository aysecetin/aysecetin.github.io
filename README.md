# aysecetin.github.io

Portfolyo sayfası. Derleme adımı yok: `index.html`, `assets/` altındaki görseller ve iki CV PDF'i. `main` dalına ittiğin anda GitHub Pages yeniden yayınlıyor.

Adres: <https://aysecetin.github.io/>

## İçerik

- Daily Brew, Color Gates Puzzle (perde arkası ve playable ad linkiyle), stajlar ve önceki projeler.
- Sağ üstteki EN/TR düğmesi dili değiştiriyor; seçim tarayıcıda hatırlanıyor, Türkçe tarayıcılar TR ile açılıyor.
- Metinlerin hepsi sayfanın sonundaki `<script>` içinde `en` ve `tr` sözlüklerinde. Bir metni değiştirirken iki dilde de değiştir; HTML'deki İngilizce metin JavaScript çalışmadığında görünen yedek.
- Footer'daki "CV'yi indir" linki dile göre `Ayse_Cetin_CV.pdf` ya da `Ayse_Cetin_CV_TR.pdf` dosyasını açıyor. CV güncellenince bu iki dosyayı değiştir.
